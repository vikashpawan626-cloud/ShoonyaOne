# 🚀 ShoonyaOne AI Assistant

**ShoonyaOne** is an autonomous personal AI assistant built for Android environments via Termux. It combines natural language understanding using Google Generative AI (Gemini) with real-world mobile automation, hardware control, and live web search.

---

## ✨ Features
- 🤖 **Conversational AI:** Powered by the Google Gemini API with persistent context.
- 🔦 **Hardware Integration:** Control Android torch/flashlight directly from commands.
- 🔋 **Battery Monitor:** Live device battery percentage and health checks via Termux API.
- 🌐 **Real-time Web Search:** Fetch up-to-date information dynamically using DuckDuckGo.
- 📝 **Session Logging:** Keeps a detailed trace of commands and activities in `shoonyaone.log`.
